🎨 What This Application Does

Girih-2-Generative-Art is a small creative tool that draws traditional Islamic star-and-polygon patterns — known as girih — using a modern, computer-generated approach. Instead of tracing a fixed drawing by hand, the application builds each pattern from a starting seed number and a set of rules. Change the seed, and a new variation appears that still feels historically authentic.

Three well-known historic girih patterns are included. Each one is layered over a recursive tree structure, which gives the resulting artwork depth and a natural, organic rhythm. Colours are drawn from historic CSS colour palettes, so the finished images look like they belong on a manuscript page, a tile panel, or a length of woven cloth.

Because every result comes from a seed, the catalogue is reproducible. Write down a seed and you can return to that exact piece of ornament months later. That makes the tool genuinely useful for design work, where consistency and repeatable output matter.

🕌 The Three Historic Patterns

Umayyad Mosque Pattern

A rich, interlocking composition inspired by the great mosque of Damascus. Dense, layered and highly decorative — well suited to large-format prints and textile repeats.

Simple Hexagram

A clean six-pointed star arrangement. Calm, balanced and endlessly repeatable, this is the pattern to reach for when you want a subtle background or a minimal, modern surface.

Esreffoglu Mosque Pattern

A more intricate floral-geometric study with fine detail. Best viewed or printed at a larger size, where the smaller shapes and line work become clearly visible.

🖱️ Using the Application

Once the download is complete and the files are in place, the application opens as a page in your web browser — Chrome, Edge or Firefox all work fine. The screen is divided into a drawing area where the pattern appears, and a set of simple controls beside it.

  1. Choose a pattern. Pick one of the three historic girih patterns: Umayyad mosque, simple hexagram, or Esreffoglu mosque.
  2. Set a seed. Type any number into the seed box, or let the application pick one for you. The pattern redraws immediately.
  3. Change the colour palette. Switch between the historic palettes to see the same geometry in a completely different mood.
  4. Regenerate. Not quite right? Nudge the seed by one and a fresh variation appears.
  5. Save what you like. When a result pleases you, keep a note of its seed and palette so you can reproduce it later for a client, a print run, or a fabric order.

🌈 Colour Palettes

The palettes are built in CSS, which means the colours behave exactly as they would on a styled web page — consistent, predictable, and easy to read on screen or in print. Each palette is drawn from a historic reference, giving combinations of deep indigo, terracotta, ochre, sage, ivory and charcoal that sit comfortably together.

Because palettes and geometry are handled separately, you can keep a pattern you love and simply try it in every palette available. This is the quickest way to find a combination for a specific product — a scarf, a cushion, a notebook cover or a tiled wall.

🧠 A Few Practical Tips

  • Write your seeds down. A seed plus a palette name is the full recipe for any image you make.
  • Print or view larger than you think you need — the finer girih details only read clearly at a generous size.
  • Try the simple hexagram first. It is the easiest pattern to understand and the most forgiving when scaled up or down.
  • If a pattern looks too busy, change the seed rather than the palette. Small seed changes tend to simplify the composition.
  • Keep a small folder of your favourite results with their seeds written next to the file names.

❓ If Something Does Not Look Right

If the page appears blank, close the tab and open it again from the folder you downloaded. If the pattern will not redraw, refresh the browser window. Make sure the whole downloaded folder is still together — moving or renaming individual files inside it will stop the pattern files from finding each other. The download link above always points to the most current version, so if you are unsure whether you have the latest files, visit it again and compare.

🧾 Project Details

Girih-2-Generative-Art is a reproducible catalogue of computational ornament, built with HTML, CSS, JavaScript and p5.js. It is intended as a generative art toolkit for designers working in fashion, textile and surface design, and as an open reference for anyone studying girih tessellation and procedural generation.
